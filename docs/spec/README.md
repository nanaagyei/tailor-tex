# Project specifications

Current implementation scope and acceptance criteria live in [GitHub Issues](https://github.com/nanaagyei/tailor-tex/issues). Read the relevant issue before starting work and use its dependencies, acceptance criteria, and validation method.

Older long-form specifications are intentionally not copied into this repository. They describe the previous product direction and can conflict with the accepted [career-evidence compiler decision](../adr/0001-career-evidence-compiler.md).
