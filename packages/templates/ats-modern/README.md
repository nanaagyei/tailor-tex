# ATS-Modern Template

A clean, single-column LaTeX resume template optimized for Applicant Tracking Systems (ATS).

## Features
- Single-column layout for maximum ATS compatibility
- Clean section headings (Experience, Skills, Education, etc.)
- Bold keyword support for ATS keyword matching
- No tables, no icons, no images for critical content
- Works with pdflatex, xelatex, and Tectonic

## Usage
1. Generate your resume with TailorTex
2. Open `main.tex` in Overleaf or your local LaTeX editor
3. Compile to PDF

## Template variables
This template uses Jinja2 templating. Variables are injected by the TailorTex rendering engine.
