# Support

## Getting Help

- **Documentation**: Check the `docs/` directory for user guides and architecture docs.
- **Issues**: Search [existing issues](https://github.com/nanaagyei/tailor-tex/issues) first.
- **Discussions**: Use [GitHub Discussions](https://github.com/nanaagyei/tailor-tex/discussions) for questions and ideas.

## Reporting Bugs

Open a [GitHub Issue](https://github.com/nanaagyei/tailor-tex/issues/new) with:

1. What you expected to happen
2. What actually happened
3. Steps to reproduce
4. Your environment (OS, Python version, Node.js version)

## Security Issues

See [SECURITY.md](SECURITY.md) for reporting vulnerabilities privately.
